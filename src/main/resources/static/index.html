🔐 SecureAuth

JWT authentication, done properly.

Spring Boot and Spring Security with short-lived access tokens, rotating refresh tokens, reuse detection, role- and permission-based access, account lockout, rate limiting and a full audit trail.

  • 15-minute HS256 access tokens, kept in memory only
  • Refresh tokens in an HttpOnly, SameSite=Strict cookie, rotated on every use
  • Instant revocation: logout, password change and role change take effect immediately
  • RBAC: USER, MODERATOR, ADMIN mapped to fine-grained permissions
